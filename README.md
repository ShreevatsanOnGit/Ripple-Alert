# Ripple Alert

Ripple Alert is an infrastructure resilience and cascading failure simulation application designed to visualize how failures propagate through interconnected infrastructure networks.

## Installation

1. Download `RippleAlert-Windows.zip` from this repository.
2. Extract the ZIP file to a location of your choice.
3. Open the extracted folder.
4. Run `RippleAlert.exe`.

No additional installation or configuration is required.

## System Requirements

• Windows 10 or later
• Microsoft Edge WebView2 Runtime
• Internet connection for map tiles
